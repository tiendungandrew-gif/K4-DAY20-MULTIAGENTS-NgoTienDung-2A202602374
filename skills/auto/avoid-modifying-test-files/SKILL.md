---
name: avoid-modifying-test-files
description: Use this skill when working with test files to ensure that original test files remain unchanged.
---
- Always create new test files instead of modifying existing ones.
- Review the test file structure and naming conventions before making changes.
- Ensure that any modifications to tests are documented and do not alter the original test logic.
- Use version control to track changes and revert if necessary.
- Validate that the test suite runs successfully after any changes to test files.
