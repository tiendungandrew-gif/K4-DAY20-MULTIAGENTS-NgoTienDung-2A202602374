---
name: handle-file-operations-correctly
description: Use this skill when performing file operations to avoid common errors related to file handling.
---
- Verify that the file paths used in your code are correct and accessible.
- Check for the existence of files before attempting to read or write to them.
- Use exception handling (try/except) to manage potential file-related errors gracefully.
- Ensure that the output file structure matches the required format before writing.
- Validate that the data being written to files is in the correct format and type.
