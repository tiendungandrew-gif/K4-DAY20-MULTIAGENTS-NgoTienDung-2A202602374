---
name: adhere-to-docstring-specifications
description: Use this skill when implementing functions to ensure they behave as described in their docstrings.
---
- Read the function's docstring carefully before implementation.
- Ensure that the function's output matches the expected format and logic described in the docstring.
- Write unit tests that specifically check the edge cases mentioned in the docstring.
- Refactor the function if the implementation does not align with the docstring.
- Regularly review and update docstrings to reflect any changes in function behavior.
